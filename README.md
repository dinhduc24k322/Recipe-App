# Ứng dụng công thức nấu ăn
## Mục đích
- Hiển thị các công thức nấu ăn
- Chức năng tìm kiếm món ăn
- Chức năng lưu các công thức yêu thích

- Gợi ý món ăn theo nguyên liệu có sẵn
- Quảng cáo các sản phẩm nhà bếp
